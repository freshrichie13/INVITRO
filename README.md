# PARADIGMA - Pre-Registro

Bienvenido al sistema de acceso de **PARADIGMA**. Este proyecto es una Single Page Application (SPA) diseñada para gestionar el pre-registro de asistentes con una experiencia inmersiva.

## 🚀 Inicio Rápido

1. **Instalación:**
   ```bash
   npm install
   ```

2. **Configuración:**
   Edita `config.ts` con tus credenciales de Firebase y EmailJS.

3. **Desarrollo:**
   ```bash
   npm run dev
   ```

## 🛠 Arquitectura de Documentación para IA
Este repositorio utiliza un sistema de contexto para agentes de IA:
- `AGENTS_CONTEXT.md`: Definición global y reglas del proyecto.
- `INSTRUCTIONS.md`: Guía de ingeniería y calidad.
- `NOW.md`: Tareas actuales y estado del sprint.
- `MEMORY.md`: Log de decisiones técnicas.

## 🎨 Estética y Diseño
La app utiliza una identidad visual de **terminal oscuro** con efectos de glitch. Los componentes clave para mantener esta estética son:
- `MatrixBanner.tsx`: Fondo de lluvia digital.
- `GlitchSound.tsx`: Capa auditiva interactiva.
- `Window.tsx`: Contenedor principal estilo OS retro.
